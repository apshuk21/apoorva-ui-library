# Apoorva UI

A modern, enterprise‑ready React UI component library built with [Vite](https://vitejs.dev/), [SCSS](https://sass-lang.com/), and [pnpm](https://pnpm.io/).  
Designed for scalability, maintainability, and teaching — every step of the build process is documented in [playbook.md](./playbook.md).

---

## Features

- Fast Dev & Build – Powered by Vite for instant HMR and lightning‑fast builds.
- Theming & Styling – SCSS with modular architecture for flexible design systems.
- Composable Components – Built with React best practices for reusability.
- Tree‑shakable – Import only what you need.
- Documented Process – See `playbook.md` for architecture, governance, CI/CD, and branching strategy.

---

## Installation

```bash
# Using pnpm
pnpm add @apoorva/ui

# Using npm
npm install @apoorva/ui

# Using yarn
yarn add @apoorva/ui
```
